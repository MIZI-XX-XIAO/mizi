# 图片人工复核分类工具 v2

离线 Windows 桌面工具：目检一个产品的指定视角，分类时自动移动该产品的全部视角图片。

## 使用方法

1. 双击 `dist\图片人工复核分类工具.exe`。
2. 选择待复核图片目录。软件只扫描当前目录，不扫描子目录。
3. 软件按文件名末尾的 `A/B/C/E/X/Y/V` 识别产品视角。例如 `产品001A.jpg` 与 `产品001B.jpg` 属于同一产品。
4. 选择本批次要目检的视角，默认是 A；开始后本批次保持不变。
5. 配置 OK、NG、RECHECK 等分类目标，最多 9 个。
6. 用数字键 `1–9` 或分类按钮归类。一次操作会把当前产品的所有视角图片移动到同一分类目录。

`Space` 暂不处理，`Ctrl+Z` 整组撤销，方向键浏览产品。目标存在任一同名文件时，整个产品都不会移动。

## 移动记录

每个分类目录维护自己的 `分类移动记录.csv`，长期追加不同任务和不同来源目录的记录。每张图片一行，包含任务编号、产品编号、目检视角、原始完整路径、来源文件夹、分类、目标路径和操作结果，可直接用 Excel 打开。

程序不会再在源图片目录生成 CSV。错误日志位于 `%LOCALAPPDATA%\ImageReviewClassifier\logs`。

## 大图性能

图片在后台解码，预览按窗口尺寸生成，连续缩放采用防抖并逐级加载清晰画面。缓存限制为 256 MB，快速切换时过期结果不会覆盖当前图片。

## 支持格式

JPG、JPEG、PNG、BMP、TIF、TIFF、WEBP。

## 从源码运行、测试与打包

```powershell
python -m pip install -r requirements.txt
python main.py
python -m unittest discover -s tests -v
.\build.ps1
```

打包结果位于 `dist\图片人工复核分类工具.exe`，支持 Windows 10/11 64 位。
